Configuration reference

All settings are made in the web interface and stored in the ESP32's flash (NVS). This page lists every field with its key, default and effect.

How settings are stored

  • Settings live in the NVS namespace hcpbridgeesp32. On the very first boot (and after a factory reset) the defaults from src/configuration.h are written; afterwards only the web interface changes them.
  • Each form saves only its own fields, then the device restarts.
  • Password fields are never sent back to the browser – they show * when set. Submitting * keeps the stored password.
  • The same data is available as JSON via GET /config and can be written with POST /config – see HTTP API.
  • The Key column is the NVS key and the JSON field name.

Resetting the configuration

  • Web interface: System information → Factory Reset (GET /reset).
  • Boot button: press it 5 times within 6 seconds (full reset) or 3 times (disable all sensors only) – see Reset button.
