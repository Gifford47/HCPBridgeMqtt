HCPBridge Documentation GitHub

HCPBridge

An ESP32 firmware that talks to Hörmann garage door operators over the HCP2 bus (RS485) and makes the door available in MQTT, Home Assistant and a built-in web interface. No cloud, no extra gateway.

Get started → Download firmware

What it does

HCPBridge emulates Hörmann's UAP1-HCP bus adapter. The operator scans its HCP2 bus, finds the ESP32 as an accessory (Modbus RTU slave 2) and from then on reports every state change to it and accepts its commands. The ESP32 forwards everything to your MQTT broker and serves a web interface on your local network.

Full door control

Open, close, stop, half-open, ventilation position, any position 0–100 % and the operator light.

Home Assistant discovery

Cover, light, switches, buttons and sensors appear automatically – no YAML needed.

Web interface

Live door animation, controls, sensor values and the complete configuration in the browser.

Optional sensors

BME280, DS18X20, DHT22, HC-SR04 parking sensor, HC-SR501 motion, MQ4 gas – enabled in the UI.

Digital I/O

In1/In2 wall-button inputs with local actions and Out1/Out2 switch outputs on the prebuilt PCBs.

OTA updates

Update the firmware from the browser; settings are kept in flash.
