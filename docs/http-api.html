HTTP API

The web interface uses a small JSON API on port 80. You can use it for scripts and other home automation systems as well.

AuthenticationWithout a web password the API is open in your network. With a password every endpoint below (except /events) requires HTTP basic authentication with user admin. The OTA page has its own login (admin / admin).

GET /statush

Compact door state straight from the bus handler: valid ("true" if the last bus request is younger than 2 s), targetPosition, currentPosition, light, state (text) and busResponseAge.

GET /command

actionEffect
0Close
1Open
2Stop (only while moving)
3Ventilation position
4Half-open position
5Toggle light
6Restart the bridge
7Drive to position (0–100; ≤ 5 closes, ≥ 95 opens)
8Toggle: open if not fully open, otherwise close
 
curl "http://192.168.1.42/command?action=1"
curl "http://192.168.1.42/command?action=7&position=40"
curl -u admin:secret "http://192.168.1.42/command?action=5"   # with web password

Returns OK (text/plain).

GET /io

Parameters output (1 or 2) and state (on/1/true, off, toggle). Returns 200 OK, 400 when a parameter is missing and 404 when the output is not enabled.

curl "http://192.168.1.42/io?output=1&state=toggle"

GET / POST /config

GET returns all settings as JSON (keys as in the configuration reference); passwords are returned as "*" when set.

POST with Content-Type: application/json saves settings and restarts the bridge. It behaves like the web forms:

  • A group is only saved when its marker field is present: device_id (basic), sen_StInterval (sensors), io_in1_pin (I/O), rs485_txd (expert).
  • Check boxes of a saved group are true only with the value "on"; a missing check box is saved as false.
  • Password value "*" keeps the stored password.
curl -X POST -H "Content-Type: application/json" \
  -d '{"sen_StInterval":"30","sen_sr04_en":"on","sen_sr04trigpin":"5","sen_sr04echopin":"27"}' \
  http://192.168.1.42/config
The example saves the whole sensor group: every sensor not listed as "on" is disabled and missing numeric fields keep their values. Read the configuration first and send the complete group.

GET /events (server-sent events)

The web interface subscribes to /events for instant updates:

EventData
sensorOne changed value incl. unit, e.g. {"temp":"21.6 °C"} or {"motion":"true"}
ioFull I/O state, e.g. {"in1":"true","out1":"false"}
 
curl -N http://192.168.1.42/events
